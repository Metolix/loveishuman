# Love Is Human

An educational reading room about love, relationships, feelings, and human connection.

Love is personal, and no single story covers it all. This project makes room for the joyful, confusing, ordinary, and difficult parts of being close to other people.

## Get started

You’ll need Node.js and npm. From the project folder, run:

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Contributing
